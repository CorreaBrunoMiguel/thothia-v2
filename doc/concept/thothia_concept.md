# 🌿 Thothia v2 — Manifesto Conceitual

## 🧭 Visão

Thothia v2 é um **catálogo técnico e interativo** da flora e fauna local,
concebido para registrar, estudar e compreender os ecossistemas através de um
olhar técnico e poético.

O projeto une **biologia, tecnologia e observação natural**, permitindo
catalogar espécies, habitats e interações ecológicas.  
Cada registro contém dados taxonômicos, bioma, status ecológico (nativa,
endêmica, invasora) e metadados geográficos.

---

## 🧬 Filosofia

Inspirada em **Thoth**, o deus egípcio do conhecimento, a Thothia busca
**traduzir a natureza em informação viva**.  
Ela é tanto uma ferramenta de estudo quanto uma ponte entre curiosidade humana e
ciência.

O sistema nasce como um **projeto pessoal e hobbie de catalogação**, mas é
arquitetado para escalar — podendo evoluir em direção a uma plataforma
colaborativa de pesquisa ecológica e ciência cidadã.

---

## 🏗️ Estrutura Conceitual

- **Núcleo:** Node.js (Express)
- **Frontend:** React + Vite (JavaScript)
- **Banco de Dados:** PostgreSQL + PostGIS
- **IA Auxiliar:** FastAPI (Python) + TensorFlow
- **Infraestrutura:** Docker + Orion Pipeline
