# 🌿 Thothia v2

**Thothia v2** é um catálogo técnico e interativo da flora e fauna local,
desenvolvido sob o **Protocolo Orion**.  
O projeto combina rigor científico e liberdade criativa, buscando registrar a
biodiversidade com precisão e beleza.

---

## 🧬 Estrutura do Projeto

```tree
/thothia-v2
├── /doc/ → Documentação viva (Metodologia Orion)
│ ├── concept/ → Ideias e manifesto conceitual
│ └── eto_fase1.md → Execução viva (fase atual)
├── /src/
│ ├── backend/ → API Node.js (Express)
│ ├── frontend/ → Interface React (Vite)
│ └── shared/ → Utilitários e modelos comuns
└── package.json
```

## Protocolo Orion

Este projeto segue a metodologia viva Orion:

- Documentação orgânica (/doc/eto_faseX.md)
- Fases compostas por Sprints → Tarefas → Subtarefas
- Cada execução é rastreável, com commits semânticos e históricos vivos.
